# Acceptance Checklist

Before returning, confirm every item:

- A real `study-room-output/index.html` file exists.
- The supplied or bundled background fills the viewport.
- The timer area remains transparent and readable.
- Users can add and select courses.
- Default focus is 25 minutes and rest is 5 minutes.
- Start, pause, continue, and end work.
- Completed focus automatically starts rest and records the selected course.
- Completed rest automatically starts the next focus.
- Today's completed count and focused minutes are shown.
- Reloading preserves courses, records, and an active countdown.
- The browser console has no errors.
- Desktop and phone layouts remain usable.
